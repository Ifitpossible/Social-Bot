# X 熱度閱讀器

獨立執行的 Chrome／Edge 本機擴充功能。啟動後由 JavaScript 程式操作專用 X 分頁，收集、擷取和排名；不使用 Codex、ChatGPT、LLM 或 X API 金鑰。這不是聊天裡的定時任務。

## 開始使用

1. 在 GitHub 點「Code」→「Download ZIP」，下載並解壓縮此倉庫。也可以使用 `git clone https://github.com/Ifitpossible/Social-Bot.git`。
2. 在 **Chrome** 開啟 `chrome://extensions`，或在 **Edge** 開啟 `edge://extensions`。
3. 開啟「開發人員模式」→「載入未封裝項目」，選擇包含 `manifest.json` 的倉庫資料夾（例如 `Social-Bot-main` 或 `Social-Bot`）。
4. 在同一個瀏覽器登入 X，再點擴充功能的「X 熱度閱讀器」圖示。
5. 保留預設「20 篇、前 5 名」，按「開始收集」。保持閱讀器本頁開啟。程式會另開一個 X 分頁；不要手動操作該專用分頁。
6. 完成後按「匯出閱讀報告」及／或「匯出完整 JSON」。

**目前聊天的內嵌瀏覽器不能用這個安裝方式。請在 Chrome／Edge 安裝；它們不會自動共用內嵌瀏覽器的 X 登入狀態。** 安裝和首次登入需要你自行完成；此交付沒有替你安裝，也沒有操作你的 X 網頁。

擴充功能只要求讀寫 `x.com` 頁面、讀取 `pbs.twimg.com` 附圖，以及本機儲存和腳本執行權限。它只會捲動、切換「為你推薦」、開啟貼文及展開正文，不會按追蹤、愛心、轉發、回覆或發文。

## 會收集什麼

- 預設擷取沿首頁捲動方向遇到的 20 篇不同貼文（可設 5–100 篇），盡力辨識並排除廣告。
- 每篇的 ID、作者、日期、正文、引用文字的可見部分、四項數字、來源連結和觀察時間。
- **所有候選都開啟單篇讀取正文**，不只讀取前 5 名。首頁數字用於排名，單篇稍後讀到的數字另外保存，不混用不同時點。
- 附圖的網址、描述與圖片檢視頁；預設將可下載的圖片嵌入本次 HTML 閱讀報告。每張最多 8 MB、總共 32 MB，超出或失敗時保留連結。
- 頁面有顯示的影片封面／直接網址。串流影片不匯出，請從原文觀看。
- 可見的外部文章卡片連結。

「所有」指**指定候選篇數內、登入帳號可見的正文與可見媒體資料**。不代表整個 X、整串回覆、X Articles 的獨立文章全文、引用貼文完整串文、外站全文或影片逐字稿。圖片不作 OCR。正文仍有「顯示更多」、貼文失效或讀取失敗時會標示部分內容，不冒稱已完整擷取。

首頁是虛擬捲動，程式邊捲邊去重。若持續沒有新貼文，會使用已取得的候選，而不是無限捲動。X 改版或語系變動可能需要更新解析規則。

## 排名規則

每一項（討論、轉發、愛心、觀看）都計算：

`校正值 = 首頁觀察時的累計數字 / (從發布到觀察時的經過小時 + 2)`

四項校正值分別在本次候選中排名，轉換為 0–100 百分位，同值取平均名次，再各占 25% 相加。同分時以校正後討論數決定，再相同就保持原採集順序。

- 不是 X 的官方 Trending 演算法。
- 不等待第二次觀察，也沒有 15 分鐘等待步驟。
- 預設單篇間隔 5 秒，可改為 3–120 秒；這是讀取間隔，與計分平滑小時不同。
- 缺少日期或四項數字的貼文，仍保存內容，但**不參與排名**。未知不是零。
- 介面只提供 `1.2K`、`2.5萬` 等縮寫時，保存近似數值及 `approximate` 標記。
- 觀看是頁面曝光計數，不是獨立觀眾數。熱度不代表內容品質或正確性，也沒有依作者平時表現校正。

## 執行與儲存

這個版本由你手動啟動一次、執行一輪。閱讀器頁面保持開啟即可執行，不需要本聊天繼續開著，也不會呼叫 LLM。沒有無限常駐排程或付費 API。

資料留在本機，不傳送到分析服務。程式直接讀取瀏覽器已顯示的頁面，沒有讀取 Cookie、權杖、瀏覽器儲存區或呼叫未公開的 X 介面。

執行遇到登入、驗證或明確頻率限制時會停止，保留部分結果與 X 分頁供你查看。單篇刪除、權限不足或載入失敗時，記錄錯誤並繼續其他候選。按停止後，正在執行的頁面讀取可能最多還需約 20 秒結束。

結果文字與數字會暫存在擴充功能本機儲存區。**圖片檔僅留在當次閱讀器頁面的記憶體，請在關閉前匯出 HTML。** 關閉後重新開啟仍可還原文字結果與圖片連結，但不含先前未匯出的圖片檔。已下載的 HTML 含成功保存的圖片，可以離線開啟。

## 已做的驗證與尚未驗證項目

此版本的開發與測試沒有由代理操作 X 網頁。已用離線 DOM 範例、20 篇合成資料，以及模擬瀏覽器 API 驗證：

- 外層貼文與引用貼文不混算。
- 英文／中文數字、縮寫與缺值。
- 正文展開、限制訊息、報告的 HTML 安全轉義。
- 以 20 篇合成資料驗證排名，範例不是任何人的真實 X 動態。
- 模擬虛擬捲動收集 20 篇、開啟全部 20 篇正文、保留原始排名數字與產生結果。

**尚未在你實際的 Chrome／Edge 擴充功能環境做連線驗證。** 第一次請用 5 篇測試，確認介面解析可用後再改回 20 篇。

## 只做離線排名

若電腦有 Node.js，可用以下方式對既有 JSON 重新排名；不開啟瀏覽器，也沒有網路請求：

```text
node rank-cli.mjs tests/trial-input.json ranked.json
```

開發測試才需要安裝套件，正常載入擴充功能不需安裝任何 Node.js 套件：

```text
npm install
npm test
```

技術參考：[Chrome scripting API](https://developer.chrome.com/docs/extensions/reference/api/scripting)、[Chrome tabs API](https://developer.chrome.com/docs/extensions/reference/api/tabs)。
